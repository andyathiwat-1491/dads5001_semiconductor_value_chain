# AI Boom and the Semiconductor Value Chain: Who Captures the Growth?

โครงการนี้วิเคราะห์ข้อมูลทางการเงินใน Dataset เพื่อสำรวจว่าหลังการเติบโตของ Artificial Intelligence ตั้งแต่ปี 2022 การเติบโตของรายได้และกำไรกระจุกตัวอยู่ในบริษัทหรือกลุ่มธุรกิจใดในห่วงโซ่อุตสาหกรรมเซมิคอนดักเตอร์ และมีความสัมพันธ์กับการลงทุนด้าน R&D และ CapEx อย่างไร

## Main Research Question

**หลังการเติบโตของ AI ตั้งแต่ปี 2022 บริษัทและกลุ่มธุรกิจใดในอุตสาหกรรมเซมิคอนดักเตอร์มีการเติบโตทางการเงินสูงที่สุด และการเติบโตนั้นสัมพันธ์กับ R&D และ CapEx อย่างไร?**

## Repository Structure

- `data/raw/` — ข้อมูลต้นฉบับ
- `data/processed/` — ข้อมูลที่ผ่านการประมวลผล

- `src/` — Source code สำหรับการวิเคราะห์
- `figures/` — กราฟและภาพประกอบ
- `docs/` — เอกสารและแหล่งที่มาของข้อมูล
- `PROJECT_PLAN.md` — แผนงานและขอบเขตของโครงการ
